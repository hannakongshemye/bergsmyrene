# Bergsmyrene

Nettside for Bergsmyrene gård, biodynamisk grønnsaksgård i Hurum.
Astro, statisk, tospråklig norsk/engelsk. Innhold i JSON, redigeres på `/admin/`.

```bash
npm install
npm run dev      # utviklingsserver
npm run cms      # lokal CMS-proxy, kjøres ved siden av dev
npm run build    # produksjonsbygg
```

Les `BRAND.md` for designgrunnlaget og `MIGRATION_NOTES.md` for hva som gjenstår
og hva som må avklares med gården.
